# Точка

Приложение-карта барбершопов, салонов красоты, маникюра, бровей, тату и СПА по всей России. 3D-карта с выбором города.
Поиск, фильтр по категориям, фильтр «Без сайта», карточки с контактами и блокнот.

Устанавливается на телефон как приложение (PWA): открыть сайт → «Добавить на главный экран».

## Как запустить на GitHub Pages

1. На GitHub нажми **New repository**, назови `tochka`, сделай **Public**, создай.
2. Нажми **uploading an existing file** и перетащи все файлы из этой папки (вместе с папкой `icons`). Нажми **Commit changes**.
3. Открой **Settings → Pages**. В «Source» выбери **Deploy from a branch**, ветка `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты приложение будет по адресу `https://ТВОЙ_НИК.github.io/tochka/`.
5. Открой ссылку на телефоне:
   - Android (Chrome): меню ⋮ → **Установить приложение**.
   - iPhone (Safari): кнопка «Поделиться» → **На экран «Домой»**.

## Откуда данные

- Карта: **OpenFreeMap** (MapLibre GL, векторные тайлы с 3D-домами), подпись источников обязательна.
- Заведения: **OpenStreetMap** через Overpass API (лицензия ODbL). Загружаются районами, когда карта приближена, и кэшируются на 7 дней.
- Карта: тайлы OpenStreetMap. Подпись «© участники OpenStreetMap» обязательна, не убирай её.
- Блокнот хранится только на устройстве пользователя.

## Перед запуском подписки

- Тайлы OpenStreetMap не для коммерческих приложений: заменить на MapTiler / Stadia Maps (строка `L.tileLayer` в `app.js`).
- Публичный Overpass не рассчитан на много пользователей: перенести данные в свою базу (например Supabase) и обновлять раз в неделю.
- Аккаунты, оплата, оферта, политика конфиденциальности, уведомление в Роскомнадзор.

## Файлы

- `index.html` — разметка
- `style.css` — оформление (светлая и тёмная тема)
- `app.js` — карта, загрузка данных, поиск, карточки, блокнот
- `sw.js`, `manifest.webmanifest`, `icons/` — установка на телефон

## Android-приложение (APK)

APK собирается автоматически на GitHub (вкладка **Actions → Android APK**) и выкладывается в **Releases**.

Постоянная ссылка на скачивание:
https://github.com/Cunbent-Present/tochka/releases/latest/download/tochka.apk

Приложение открывает сайт `cunbent-present.github.io/tochka`, поэтому все изменения сайта сразу видны и в APK — пересобирать его не нужно. Код обёртки лежит в папке `native/`.

## Страница загрузки

`download.html` — страница со ссылками на APK, установщик Windows и инструкцией для iPhone. Сама показывает первой карточку под устройство посетителя. Ссылка для людей: https://cunbent-present.github.io/tochka/download.html

## База салонов

Папка `data/` — своя база заведений **по всем регионам России** (из OpenStreetMap): все города, посёлки и сёла. Её раз в неделю обновляет GitHub (**Actions → Обновить базу салонов**, можно запустить вручную кнопкой Run workflow). Один запуск работает до ~4,5 часов и сохраняет результат по ходу; что не успел — обновит следующий, начиная с самых старых регионов.

Приложение грузит файлы только тех регионов, что рядом с центром карты. Там, где базы нет (например, за границей), заведения по-прежнему грузятся живьём.

## Для поиска клиентов

- **Потенциал клиента** (0–100): насколько заведению нужен сайт — нет сайта, только соцсети/онлайн-запись, есть ли контакты. В списке есть сортировка «Клиенты».
- **Написать**: шаблоны сообщений с подстановкой названия, кнопки Telegram / WhatsApp / VK / Email, запись в блокнот и напоминание.
- **Блокнот**: статусы, напоминания, экспорт в Excel (CSV).
- **Добавить заведение**: кнопка с булавкой справа — место сохраняется на устройстве.
