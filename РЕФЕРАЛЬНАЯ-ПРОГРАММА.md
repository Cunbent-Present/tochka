# Реферальная программа «Точки»

Пригласивший получает 7 дней Pro после регистрации друга с подтверждением почты и ещё 30 дней после его первой оплаты. Бонус прибавляется к действующему сроку Pro. Если доступ закончился, срок начинается с момента начисления. Друг сохраняет обычные три пробных дня и оплачивает подписку по обычному тарифу.

## Включение

1. Убедиться, что в Supabase уже созданы `subscriptions` и `payments` (из `supabase/payments.sql`).
2. Выполнить `supabase/referrals.sql` в Supabase SQL Editor. Если файл уже выполняли до исправления срока пробного доступа 27 ноября, запустить обновлённый файл ещё раз. Повторный запуск не повторяет начисление бонусов.
3. Опубликовать изменённые `index.html` и `app.js` вместе с остальными текущими файлами приложения. До установки SQL блок приглашений скрыт.

## Как начисляются бонусы

- Пользователь копирует личную ссылку из профиля. Новый пользователь открывает её, получает код на почту и подтверждает вход. При следующем запросе статуса сервер закрепляет приглашение и добавляет 7 дней пригласившему.
- Ссылка привязывается только к аккаунту, созданному не раньше 48 часов назад; уже привязанный аккаунт, самоприглашение и уже оплативший пользователь не дают бонус.
- После первой подтверждённой онлайн-оплаты 30 дней начисляются автоматически. Повторное уведомление о том же платеже не начисляет бонус заново.
- Если оплата пришла переводом, администратор после проверки денег нажимает для аккаунта покупателя «Оплата +1 мес». Это продлевает его Pro на месяц и начисляет пригласившему 30 дней. Обычная кнопка «+1 мес» служит для продления без фиксации оплаты.

Проверка перед публикацией: зарегистрировать два новых тестовых аккаунта, открыть ссылку пригласившего вторым аккаунтом и подтвердить почту; проверить срок Pro и счётчик приглашений у первого. Повторный вход второго не должен менять срок. Для ручной оплаты проверить «Оплата +1 мес» и убедиться, что следующая оплата того же друга не добавляет пригласившему новые 30 дней.
