# Push-уведомления о новых заведениях

«Точка» отправляет уведомление на подписанное устройство после обновления базы, если в выбранном городе появились новые заведения без указанного собственного сайта. Проверяются именно новые ID заведений; первый запуск запоминает текущую базу и ничего не рассылает.

## Однократное включение

1. В Supabase откройте **SQL Editor** проекта «Точка», вставьте и выполните содержимое [`supabase/push_notifications.sql`](supabase/push_notifications.sql).
2. В GitHub откройте **Actions → «Новые заведения — push» → Run workflow**. Первый запуск создаст пару ключей Web Push в защищённой таблице Supabase и запомнит уже существующие заведения. Новый секрет не нужен: workflow использует `SUPABASE_SECRET_KEY`, который уже нужен сборке базы.
3. В «Точке» войдите в аккаунт, выберите город в личном кабинете и нажмите **«Включить уведомления»**. Подтвердите запрос браузера. Подписка привязана к этому устройству; на другом устройстве её нужно включить отдельно.

После следующих обновлений базы workflow «Новые заведения — push» запускается автоматически вслед за «Обновить базу салонов». Если новых заведений нет, уведомление не отправляется. Отключить уведомления можно той же кнопкой в личном кабинете.

На iPhone и iPad push для веб-приложения работает после добавления «Точки» на экран «Домой» и запуска с этого экрана. В обычной вкладке Safari кнопка объяснит, что нужно сделать.

Таблица `push_subscriptions` хранит адрес доставки и ключи шифрования для каждого устройства. Пользователь может читать и менять только свою подписку. Приватный ключ отправки доступен только серверному ключу; в публичном API виден лишь публичный ключ. При выходе из аккаунта приложение отписывает устройство.
